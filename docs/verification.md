## 邮箱：自定义域名（IMAP）邮箱接入（2026-11-08）

用户填自己的 Gmail 地址时被「该域名不支持直接接入」拒绝——那只是「地址即信箱」渠道的限制。本轮新增自定义域名邮箱：地址 + 应用专用密码/授权码，用 IMAP 只读收件。

- 新增 `admin-panel/mailimap.go`（channel id `imap`）：implicit TLS 993、整体 20s deadline、tag/`{N}` 字面量解析、`ID` 可选扩展、LOGIN 引号转义、`SELECT INBOX`、最近 20 封的 UID + HEADER.FIELDS 列表、`(BODY.PEEK[HEADER] BODY.PEEK[TEXT])` 取正文后用 `net/mail` + `mime/multipart` + quoted-printable/base64 解析，优先 text/plain，回退 `mailStripHTML(HTML)`；整条消息缓存 60s / 50 条，缓存命中在建立连接之前返回（页面每 5 秒的 `/code` 不再重复登录）。
- 安全：host 只接受主机名（正则要求带点且末段以字母开头），拒绝 IP 字面量、`localhost`、端口与路径，端口固定 993，因此浏览器传来的值不能变成任意 TCP 探测；所有错误为固定中文文案，不透出服务器原文或凭据；凭据只存 `data/mail.json`（0600），关闭记录时清除。
