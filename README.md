# SMS 比价导航

聚合多个接码平台的公开报价，在一个页面里按接码对象、国家、渠道、租期等条件比较价格，再跳转到对应平台官网完成购买、收码与续费。另含一个多渠道临时邮箱工作区，用于接收验证码。

- 平台名单与接入状态：[平台清单](docs/platforms.md)
- 本仓库只读取各平台公开资料，不涉及账户、余额、密钥或验证码的收集。

## 在线使用

**用浏览器打开网页即可，无需下载、无需安装、无需任何密钥。** 页面是纯静态单页，报价每天自动发布更新，刷新即为当天最新。

**网址：<https://kjj-byte.github.io/sms/>**

- 筛选与报价卡片需要 JavaScript；禁用时给出文字说明
- 购买、收码、退款、续费均在对应平台官网完成，本站不代办任何交易

## 功能

- **接码比价**：选择对象 → 比较渠道 → 前往官网。支持关键词实时搜索、按国家/渠道/租期/退款等筛选，结果为卡片式报价。
- **报价口径**：逐条标明具体价、公开起价、未知或需登录；同一条件下按精确数值排序，非美元报价附参考折算与原币种原价。
- **临时邮箱**：内置多渠道临时收件箱，可创建免费邮箱或接入已有邮箱（IMAP），用于接收验证码；详见 [邮箱功能](docs/mail.md)。

## 维护者

报价采集与页面发布由维护者在本机完成：`priceupdate` 抓取各平台公开价格 → 生成静态页面到 `dist/` → 发布到 `gh-pages`。每日由计划任务自动执行，全流程不调用模型、不需要模型凭据。真实密钥保存在本地且不提交。

- 价格更新与数据来源：[价格更新说明](docs/price-updates.md)
- 构建、架构与命令：[项目指南](docs/PROJECT-GUIDE.md)
- 验收记录与限制：[验收记录](docs/verification.md)

## 数据说明

- 事实日期以各条记录为准；人工规则超过 7 天、自动价格超过 24 小时标记为待更新。
- 自动采集的最低价是公开起价，不代表精确成交价；未知、需登录、来源失败与规则冲突分开显示。
- “跨国起价”可能由逐国报价汇总，不代表某个国家可用。一个月不当成 30 天。
